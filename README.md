# AI Personal Expense Categorizer

Simple tool that automatically categorizes your expenses from text (or bank statement lines) into categories like Food, Travel, Shopping, Bills etc.

Uses keyword matching + basic ML feel. Great practical project.

## Features
- Paste expense lines one by one or in batch
- Auto category assignment
- Monthly style summary
- Easy to customize categories & keywords

## How to Run (Google Colab)

1. Open Google Colab
2. Copy code from ``expense_categorizer.py` + **`Expense_Categorizer.ipynb`**`
3. Run and start pasting expenses

## Installation (Local)

```bash
pip install -r requirements.txt
python `expense_categorizer.py` + **`Expense_Categorizer.ipynb`**
```

## Tech Stack
- Pure Python + simple rules + optional scikit-learn
- Easy to upgrade to real ML later
